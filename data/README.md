## Dataset

This project uses a publicly available healthcare insurance claims dataset from Kaggle.

**Source:** [Healthcare Claims Dataset by lakshmijetty](https://www.kaggle.com/datasets/lakshmijetty/healthcare-claims-dataset)

**To reproduce this analysis:**
1. Download the dataset from the link above
2. Import it into DB Browser for SQLite
3. Run `sql/data_cleaning.sql` first
4. Then run `sql/exploratory_analysis.sql`
