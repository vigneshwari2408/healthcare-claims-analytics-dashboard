## Data Dictionary

| Column | Description | Example |
|--------|-------------|---------|
| claim_id | Unique identifier for each insurance claim | CLM-0001 |
| patient_id | Unique patient identifier | PAT-001 |
| claim_amount | Total billed amount for the claim (USD) | 1250.00 |
| approved_amount | Amount approved by the payer | 980.00 |
| claim_status | Current status: Approved / Denied / Pending | Denied |
| denial_reason | Reason code for denied claims | Missing Authorization |
| payer_name | Insurance company name | Blue Cross |
| procedure_code | Medical procedure identifier | 99213 |
| submission_date | Date claim was submitted | 2023-01-15 |
| processed_date | Date claim was processed by payer | 2023-01-22 |
